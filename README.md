# DCM MAP 对比工具

**当前版本 v1.2.0（2026-11-14）** · 作者 Henry

离线单文件 HTML，用来对比 DCM 标定数据：把若干张 MAP 放进对比清单、指定基准，逐格算差异并定位到具体工况；也能对两份 DCM 的全部标定量做版本审查，产出可评审、可归档的 HTML 报告。

**双击 `DCM_MAP_对比工具.html` 即可使用**，无需安装、无需联网、无外部依赖。文件只通过浏览器 File API 在内存里解析，不上传、不写系统目录。

---

## 快速开始

1. 点「载入 DCM」或把 `.DCM` 拖进虚线框，可一次载入多份做版本对比。
2. 左侧按**同轴组**聚类（轴数值完全相同的一批表），点「整组加入」把整批 MAP 放进对比清单；点标签切换基准。
3. 切页签看差异，最后点「导出 HTML 报告」或「全量变化报告」。

顶部「查看使用手册」按钮打开内嵌手册（10 章：界面地图、差异规则、3D 曲面 7 种模式、两种报告、评审批注与归档、分享 FAQ），支持 Esc / 点遮罩关闭与打印存 PDF。

需要审查「两版之间有哪些标定改动」时，载入两份 DCM → 点「全量版本对比」或直接切到「全量变化清单」页签 → 生成清单 → 导出全量变化报告。

## 功能地图

工具共 10 个页签：

| 页签 | 用途 |
|---|---|
| 差异热力矩阵 | 逐格 Δ / 原值 / 相对差，可切最大偏差包络、只看变化格 |
| 切面曲线叠加 | 固定一行或列，把基准 + 全部对比叠在一条曲线上 |
| 3D 曲面 | 7 种模式：差曲面、基准、对比、双曲面、A 最大偏差包络、B 曲面小多图、C N 张叠加（默认叠加 / 拉开距离，间距可调、逐层可开关）；三轴标真实数值刻度，可拖拽旋转、滚轮缩放、「定位轴值」高亮曲面带 |
| 跨版本剖面 | 选一个工况格（或直接点热力矩阵格子），看它在各层上的取值曲线与相对基准的偏差 |
| 逐格明细 | 坐标、两边原值、Δ、相对差、来源文件与 DCM 行号 |
| 版本变更清单 | 跨版本同名对象全量扫描，只列有变化者，可一键加入对比清单 |
| 改名对齐 | 相邻两版间找改名候选（名称 + 轴指纹 + 数值相似度、双向唯一），只给候选不自动合并 |
| 轴变更影响面 | 按完整轴指纹反查「改一根轴波及多少张表」，报断点变化类型与全部受影响表 |
| 全量变化清单 | 全部标定量的变化账本，含恒等式对账、类型/状态筛选、逐项证据与评审 |
| 说明 | 内置帮助 |

其他：对比摘要（改动模式、热点工况区间、体检、超差区间，只陈述事实不给建议）、会话存/读 JSON（复现对比清单与视角）、解析自检（内置变异测试）、自动阈值。

## 两种报告

| | 导出 HTML 报告 | 全量变化报告 |
|---|---|---|
| 入口 | 「导出 HTML 报告」 | 「全量变化报告」/ 清单页内按钮 |
| 内容 | 对比清单内各表的完整证据：自检、对比摘要、热力/曲线/3D 曲面/剖面、逐格明细 | 按对象类型分章，只列变化项（含新增/删除/被拒绝），未变化项只给计数与恒等式对账 |
| 结论 | 对比摘要只陈述事实，不给放行/驳回建议 | **只陈述事实，不给放行/驳回/处置建议** |
| 用途 | 看某几张表的差异细节 | 标定变更评审、发布前核对 |

两份都是自包含离线 HTML，内联 SVG 矢量、零外部资源，双击即开、可直接转发。报告的页头标注 `作者 Henry · 供标定评审使用`，页脚带使用声明（保留署名、未经许可请勿转售或二次分发）；归档版沿用同一份 DOM，声明一并保留。工具自身页脚写「供内部标定评审使用」，报告端不写「内部」，避免对外发时口径自相矛盾。

## 评审批注与归档

报告顶部有两个按钮：

- **另存含批注的可编辑副本**：生成一份含最新批注、仍可编辑/再导出的 HTML。
- **导出归档报告**：弹出中央手写签名板，手写签名确认后把签名图像、归档时间、报告 ID 写入输出报告；归档版批注控件全部禁用、移除再次导出入口。

批注**实时自动保存在本机浏览器**（按报告 ID 隔离），重新打开同一份原报告会自动恢复、仍可继续编辑。**实时保存仅在本机生效**——换电脑、换浏览器、清浏览器数据或转发给同事，批注不会跟着文件走；浏览器也无权改写本地磁盘文件，所以要让批注固化进 HTML 文件本身，必须用「另存含批注的可编辑副本」或归档版。

变化项、新增项、删除项、被拒绝项都有同样的评审框（结论 / 意见 / 需求号 / 责任人）。在**全量变化报告**里，**轴定义整块内容统一集中在「轴定义断点变化类型」一节**：分章统计行、断点变化类型分类、序列对照、Δ 剖面图与逐点证据表、以及全部轴定义变化的评审批注（断点数值变化、断点增删、B 版新增、B 版删除）。「按对象类型分章」只保留类型总览表与数值标定量的分章证据，「新增 / 删除 / 被拒绝对象」只列清单，都不重复展开轴定义或放批注控件，避免同一账目 id 出现两组控件互相覆盖。工具「全量变化清单」页签里仍可对所有项逐项写评审。

> 签名是手写痕迹，不是数字签名；**本版本不做防篡改**。纯离线单文件 HTML 做不到真防篡改（指纹写在报告里可一并重算），需要真防篡改就得引入外部信任锚，与单文件离线约束冲突。

## 数据格式与实测基线

支持 DAMOS `KONSERVIERUNG_FORMAT 2.0`，GB2312/GBK 解码（`gbk → gb18030 → gb2312` 依次尝试）。解析的块类型：

| 块 | 映射类型 |
|---|---|
| `FESTWERT` | 标量 |
| `FESTWERTEBLOCK` | 一维数组 |
| `GRUPPENKENNLINIE` / `FESTKENNLINIE` / `KENNLINIE` | 曲线 |
| `GRUPPENKENNFELD` / `KENNFELD` | 二维 MAP |
| `STUETZSTELLENVERTEILUNG` | **轴定义（正式标定量）** |
| `*3D` 类 | 明确列出「格式未经实测」，仅解析第一层，排除出对比账本 |

`ST/X`、`WERT` 会折行，按块头 `NX/NY` 声明收齐；每个 `ST/Y` 后的 `WERT` 是一整行数据。逐块校验点数，异常块报文件名与行号。轴是否相同按**轴数值数组**判断，不按 `*SSTX` 引用名（本文件里轴引用名几乎一对一，按名字分组会把 60 张同轴表拆散）。

以 `ALL.DCM` 实测（200,970 行 / 7.7 MB）：

| 项 | 数量 |
|---|---|
| 块总数 | 22,813（异常 0、未识别行 0） |
| 数值标定量 | 21,090 = 标量 18,089 + 数组 1,926 + 曲线 424 + MAP 651 |
| 轴定义 | 1,723 |
| **全量账目对象** | **22,813**（数值标定量 + 轴定义，恒等式通过） |
| 2D 同轴组 | 159 个，最大组 60 张 15×11 |

全量审查约 290–490 ms，2×7.7 MB 在浏览器内约 350 ms 解析完。

## 差异与体检规则

- 轴数值完全一致 → 逐格相减（默认、最可信）。
- 维度相同但轴刻度不同 → 双线性插值对齐到基准轴，界面与报告显著标记「已插值」，不要当原始值。
- 维度不同 → 直接拒绝并说明原因，不硬凑。
- 轴断点非单调或有重复 → 插值对齐**明确拒绝**，不给一个看着正常的错误结果。
- 相对差在基准为 0 时降级为绝对差并标记；小于阈值的差视为未变化（阈值可切「自动」，按量纲推算）。
- **体检按对象类型分派**（避免把标量/轴断点套进二维四邻域判据）：

| 类型 | 判定口径 |
|---|---|
| 标量 | 只有一个值，孤立突变点 / 趋势反转判据不适用 |
| 一维数组 / 曲线 | 左右邻域 + 单轴（X）趋势反转 |
| 二维 MAP | 四邻域孤立点 + X/Y 双轴趋势反转 |
| 轴定义 | 逐点比较断点值；改单个断点是正常标定，不判孤立点；改后是否单调、有无重复断点才是指标 |

轴定义是正式标定量：断点值变化逐点给 Δ + 一维剖面图；断点增删按整项变化计入并给两版序列对照表；新增/删除的轴定义显式列出。全量变化清单**不做改名配对**（改名对象分别落在 B 版删除与 B 版新增，由人对照），改名对齐是独立页签的可选功能。

## 源码结构

```
src/core.js      解析、索引、对齐、差异、全量账本、体检、轴影响面（纯逻辑，无 DOM）
src/views.js     热力矩阵、曲线、3D 曲面（自绘 SVG）、跨版本剖面、类型化证据表
src/report.js    两种 HTML 报告的构建/下载、批注同步、手写签名与归档冻结、报告 CSS
src/ui.js        交互层：树、对比清单、页签、事件委托、会话存读、自检
src/style.css    工具界面样式
src/version.js   版本号与更新记录（唯一来源，build 注入并校验）
src/shell.html   页面骨架，含 STYLE/VERSION/CHANGELOG/CORE/VIEWS/REPORT/UI 七处占位符（双大括号包裹）
build.js         把 src/* 拼装成单文件交付物；校验 README 最新版本与 version.js 一致
test_core.js     解析回归 + 变异测试（Node）
test_bundle.js   产物静态检查 + 报告渲染断言（Node）
test_browser.js  无头 Edge 真实 DOM 交互测试（CDP，不截屏不录屏）
```

`src/core.js` / `views.js` / `report.js` 是 UMD 双写：Node 下可 `require`，浏览器下挂 `DCMCore` / `DCMViews` / `DCMReport`，宿主环境注入 `module` 也不会白屏。

## 构建与测试

只需 Node.js（无 npm 依赖，全用内置模块）：

```bash
node build.js          # 生成 DCM_MAP_对比工具.html
node test_core.js      # 解析/差异/账本/变异测试
node test_bundle.js    # 产物与报告静态断言
node test_browser.js   # 无头 Edge 真实 DOM 交互测试
```

- `test_core.js` / `test_bundle.js` 默认读 `E:/Project/DCM/ALL.DCM`，可用参数覆盖：`node test_core.js <你的.DCM路径>`。
- `test_browser.js` 需本机 Edge（`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`），真实大文件段落若文件不存在会 SKIP。
- 三套测试当前全绿：**core 209 / bundle 354 / browser 462 条 PASS，0 FAIL**（统计口径 `grep -c "^  PASS"`，不含 `ALL PASS` 汇总行）。
- 验收原则：每项功能配变异测试与 revert-to-fail（把实现改回坏版本，断言必须变红）；外部接口返回成功时独立验证副作用，不拿返回值当「事情做成了」的证据。

## 边界与隐私

- 单文件离线、不联网、不写系统目录、不截屏不录屏；DCM 只在浏览器内存里解析。
- 三轴查找表格式未经实测，遇到时明确列进自检告警并排除出对比账本，不伪装成完整三维结果。
- 「全量变化报告」只列变化项，未变化项只做计数与完整性对账，不列清单。
- 未识别块不会静默丢弃，会列进自检告警。
- 浏览器下载不会自动覆盖原文件，同名文件浏览器会加 `(1)`，替换需手工完成。
- 报告 CSS 与工具 CSS 独立维护，改样式时两边都要同步。

### v1.2.0（2026-11-14）

**删掉 3D 立方，把剖面提成独立页签**

- 立方实测两处硬伤：① 每层先铺一张 `fill-opacity:0.72` 的整块白平面，9 层叠完最下层只剩 `0.28³ ≈ 2%`，实际只看得到最上面 1–2 层；② `scale` 写死 175，投影 y 为 −43~513（画布 0~470），上下各切 43px。它的能力与「N 张曲面叠加」重叠，修到可用不如删掉。
- 页签 `3D 立方 / 剖面` → `跨版本剖面`（`data-view="cube"` → `"profile"`），`state.opts.cube {start, activeLayer, i, j}` → `profile {i, j}`，删除只被立方页使用的 `currentLayerHeat()`。
- `svgProfile` 升级：基准层虚线参考线、相对基准 Δ 范围写进副标题、层数 >12 时按 `ceil(n/10)` 抽稀 X 轴标签（21 层实测 8 个标签）。
- 新增两处交互：热力矩阵点任意格子 → 切到剖面页并定位到该格；`profileMax` 扫描所有层找 `|Δ|` 最大的一格并定位。
- **顺带修掉一段死代码**：原立方页的取点分支写在 `if (!b) return` 之后，而格子本身没有 `data-cmd/data-act`，所以永远进不去——「点格子取点」从来没生效过。新实现把格子判定提到按钮判定之前。
- 报告同步：删除立方图，章节改名「跨版本剖面」，`opts.cube` → `opts.profile`，「未进入立方体的对象」→「未纳入第三维的对象」。

### v1.1.3（2026-11-14）

一次 3D 准确性核查，查出 4 处「画错或读错」。几何本身（X/Y 不转置、Z 方向、深度排序、轴刻度与面映射）用合成斜坡表验过是对的。

1. **画布裁切**：`scale` 写死 190，默认 `yaw .72 / pitch .86` 下投影 y 为 −61~531（画布 0~470），上下各切 61px；扫全 yaw×pitch 最坏 138px。改为 `fitScale()` 按 8 个角点 + 轴标签锚点反推缩放，`opts.scale` 变成「倍数」，`state.opts.surface.scale → zoom`（1 = 刚好放下，滚轮 0.55~2.4）。
2. **网格穿模**：`axisSvg` 整段在曲面之后拼接，地面网格压在面上；差曲面最低点正好落在 `z0` 平面，网格线与面重合。`axisSvg` 拆 `part:'grid'|'frame'`，绘制顺序改为 网格 → 曲面 → 轴线/刻度，4 种 3D 视图统一。
3. **双曲面值域**：`both` 模式两版共用 `bd.lo/bd.hi`（只取基准版），对比版超出部分映射到 [−0.75,0.75] 之外。基准恒为 0 时实测飞到 5876px。改为两版并集。
4. **色标刻度**：`base/other/both` 用 `sd`（对比版）范围标注 sequential 色标，而着色用 `bd`（基准版）范围。改用 `axisLo/axisHi`。

测试新增分段 3l：yaw×pitch 扫 360 组断言不出画布（顶点 + 文字）、双曲面极端夹具、网格用 `#E8E6DF` 判定在面之前、色标用「基准极值 > 对比极值」的夹具。回退三处时对应断言全红。

### v1.1.2（2026-11-13）

- **根因**：拖动时 `ui.js` 传 `coarse: true` 走降采样，`surfaceData` 的步长从 26×22 降到 12×10，**且 Z 值域只统计抽样点**。两次采样的极值不同 → Z 归一化不同 → 曲面的起伏和配色在拖动与松手之间整体变化，看起来就是「线不一致」。
- **修法**：①值域改为扫全矩阵（极值不再受采样影响）；②取消拖动降采样，静止与拖动用同一密度（上限 26×22，实测真实 15×11 表 560 个面片，拖动依然跟手）。`coarse` 选项与 `state.opts.surfaceDragging` 一并删除。
- 顺手：拖动时隐藏悬停提示，避免提示框停在原地像图里多出一块。
