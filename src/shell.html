2. 左侧按同轴组聚类（轴数值完全相同的一批表），点「整组加入」把整批 MAP 放进对比清单；点标签可切换基准。

差异规则

轴一致 → 逐格相减；同维度但轴刻度不同 → 双线性插值并显式标记；维度不同 → 直接拒绝。相对差在基准为 0 时降级为绝对差。

支持 DAMOS KONSERVIERUNG_FORMAT 2.0（GB2312/GBK）。全过程在本地内存解析，不联网、不上传、不截屏。

DCM MAP 对比工具 · 使用手册

单文件离线工具 · 不联网 · 数据不上传 · 按 Esc 或点外侧关闭

1. 快速上手（三步）

  1. 载入 DCM：点右上角「载入 DCM」（可一次选多份），或把 .DCM 拖进上方虚线框。做跨版本对比至少需要 2 份。
  2. 加入对比清单：左侧按「同轴组」聚类，点「整组加入」把一整批同轴 MAP 放进对比清单；也可单个点「＋」。在「基准」下拉里指定一张，其余自动成为对比项。
  3. 看差异、出报告：切页签看热力矩阵、切面曲线、3D 曲面、跨版本剖面、逐格明细；最后点「导出 HTML 报告」或「全量变化报告」。

对比清单的规则是 1 张基准 + N 张对比。点清单里的标签可切换基准，「同名自动配对」把不同 DCM 里的同名对象一次拉进来，「清空」全部移除。

左侧与主区

左侧是「数据源」与「检索与分组」（按名称 / 功能 / 维度搜索；分组方式：同轴组 / 跨版本 / 全部对象）。同轴组按轴数值数组聚类，不按 *SSTX 引用名——DCM 里引用名几乎一对一，按名字分组会把 60 张同轴表拆散。

3. 载入与解析

  • 格式：DAMOS KONSERVIERUNG_FORMAT 2.0，GB2312 / GBK 编码（工具自动解码，不要按 UTF-8 另存）。
  • 解析对象：FESTWERT 标量、FESTWERTEBLOCK 数组、GRUPPENKENNLINIE / FESTKENNLINIE 曲线、GRUPPENKENNFELD 2D MAP、STUETZSTELLENVERTEILUNG 轴定义。轴定义是正式标定量，参与变化清单与完整性对账。
  • ST/X、WERT 会折行，工具按块头声明的 NX/NY 收齐；每个 ST/Y 后的 WERT 是一整行数据。逐块校验点数，异常块报文件名与行号，不静默跳过。
  • 遇到未识别块不丢弃，会列进自检告警并标注「格式未经实测」。三轴查找表当前仅解析第一层：全量变化账本一律判「对比被拒绝」；对比清单里只按第一层参与计算，列表项与报告都标注「3D·仅第一层」，不伪装成完整三维结果。

实测基线（示例 ALL.DCM）：22,813 个块 = 21,090 个数值标定量 + 1,723 个轴定义；651 张 2D MAP 聚成 159 个同轴组，最大一组 60 张 15×11。全量审查约 0.3~0.5 秒。

4. 差异规则与 3D 曲面

情况处理
轴数值完全一致逐格相减，默认且最可信
维度相同、轴刻度不同双线性插值对齐到基准轴，界面与报告显著标记「已插值」，不要当原始值
维度不同直接拒绝并说明原因，不硬凑
轴断点非单调或有重复明确拒绝插值并列出原因，不给一个看着正常的错误结果

相对差在基准值为 0 时降级为绝对差并标记；小于阈值的差视为未变化。自动阈值按量纲推算（连续量按量级 × 1e-6，整数枚举 / 开关量沿用 1e-9）。

3D 曲面的 7 种模式

模式作用
差曲面 Z=Δ1 基准 + 1 对比的差
基准 / 对比 / 双曲面叠加单对查看
最大偏差包络（A）每格取 N 张对比里偏差最大的那张，可切「按来源表」着色，看峰值由哪张表造成
曲面小多图（B）每张表一张小曲面，统一 Z 值域与色标，一眼扫出哪张形状不一样
N 张叠加（C）「默认叠加」同 Z 基准半透明叠合；「拉开距离」沿第三维分层，间距可调、逐层可开关

7 种模式共用一套视角参数：图上拖动旋转、滚轮缩放、可复位。X/Y 标真实轴断点值与单位，Z 按值域标 5 档，底板带刻度网格；「定位轴 / 定位值」把某个 X 或 Y 值对应的曲面带用橙色描边标出，用于定位具体工况点。

5. 变更体检与对比摘要

体检：孤立突变点（变化格四邻域全没变，误改的最强信号）、沿轴趋势反转、风险等级 高 / 中 / 低。按对象类型分派：标量没有邻域与沿轴趋势，孤立点与趋势反转判据不适用；一维数组 / 曲线只看左右邻域与 X 方向趋势；二维 MAP 保留四邻域 + 双轴判定；轴定义是断点序列，改单个断点属正常标定，改后是否单调、有无重复断点才是指标。

对比摘要（统计区上方）：改动模式（整体缩放 / 局部调整 / 单点修正 / 形状重构）、方向、变化最密集的真实轴值区间、体检汇总。填「允许偏差」后列出所有超差工况区间（真实 X/Y 轴值）。它只陈述差异事实、供评审参考，不给放行 / 驳回建议——结论由评审人在批注里写。报告首段就是这段摘要。

注意：全量变化报告只陈述事实，不给放行 / 驳回建议；对比摘要同样只陈述事实，也不给建议。放行与否由评审人判断并写进批注。

7. 评审批注与归档（最容易混淆的一层）

  1. 工具内：对比摘要下方可对每个对比项写结论 / 意见 / 需求号 / 责任人；「全量变化清单」页签点任一变化项的「证据」，有变化 / 新增 / 删除 / 被拒绝都能同样写评审。批注随会话 JSON 与 HTML 报告一起导出。
  2. 报告内实时保存仅在本机生效：批注一输入就写入本机浏览器存储，重新打开同一份原报告会自动恢复、仍可继续编辑。换电脑、换浏览器、清浏览器数据、直接把原文件发给同事 → 批注全丢，因为磁盘上的 HTML 一个字节都没变。
  3. 要跨机器 / 转发：点「另存含批注的可编辑副本」，生成一份内嵌最新批注、仍可编辑 / 导出的新 HTML（DCM_MAP_原报告_含批注_日期.html）。用它覆盖原文件或转发给下一位评审。
  4. 签核归档：点「导出归档报告」→ 浏览器中央弹手写签名板（鼠标 / 触摸 / 触控笔通用）→ 手写签名确认。签名 PNG、归档时间、报告 ID 写入输出报告；归档版批注只读，控件禁用、不再提供编辑与再次导出入口。没落笔不许确认，取消不导出。

边界：签名是手写痕迹、可复制，不是数字签名；本版本不做防篡改，归档版不具备密码学保证。浏览器不能直接改写本地磁盘文件，下载同名文件不会自动覆盖原文件（浏览器会加 (1)），替换需手动。

8. 会话复现

「保存会话」把数据源、对比清单、基准、阈值、当前视图、3D 视角、定位值与批注存成 JSON；「载入会话」按文件名 + 名称重新绑定，找不到再按名称 + 轴指纹模糊绑定，仍找不到的明确列为未绑定，不静默丢弃。

要完整复现，对方还得有同名 DCM 文件——工具 HTML 本身不含任何标定数据，只发工具 + JSON 不够。

10. 边界与隐私

  • 三轴表格式未经实测：全量变化账本一律判「对比被拒绝」，对比清单里只按第一层二维数据参与计算，列表项、对比清单与报告均标注「3D·仅第一层」；未识别块不静默丢弃。
  • 全量变化清单不做改名配对：改名对象分别落在 B 版新增与 B 版删除里由人对照；「改名对齐」是独立页签的可选功能，只给候选。
  • 工具不联网、不上传、不截屏、不录屏、不写系统目录；文件只通过浏览器 File API 在内存里解析。
  • 归档签名不构成身份认证，本版本不做防篡改。
